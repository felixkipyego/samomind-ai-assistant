# SamoMind AI Assistant

WordPress plugin that keeps a SamoMind AI assistant's knowledge base in sync
with the site's public content.

- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- API contract: [docs/API_CONTRACT.md](docs/API_CONTRACT.md)

## Development

```sh
composer install
composer lint     # PHPCS, WordPress Coding Standards
composer compat   # PHP 7.4 compatibility
composer test     # unit tests, no WordPress needed
```
