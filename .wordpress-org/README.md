# WordPress.org assets

These images go to the SVN `assets/` folder (a sibling of `trunk/`), not into
the plugin zip: `.distignore` leaves this folder out. Names and sizes are the
ones WordPress.org requires.

| File | What it is | Size |
|---|---|---|
| `icon-128x128.png`, `icon-256x256.png` | plugin icon: deep purple #300A6E tile with the white mark (`samomind-mark-dark.svg` from the Samomind logo pack) | 128 and 256 px square |
| `banner-772x250.png`, `banner-1544x500.png` | page banner: deep purple #300A6E background, the white lockup (`samomind-mono-white.svg`) and the line "Answers your visitors from your own site" | 772 x 250 and 1544 x 500 px |
| `screenshot-1.png` | Samomind > Settings with the chat widget switched on (demo site, fake key) | 1280 x 1400 |
| `screenshot-2.png` | the content types list and the sync status (demo site, fake data) | 1120 x 800 |
| `screenshot-3.png` | the chat widget's welcome screen on https://samomind.com (Samomind's own site) | 1280 x 800 |
| `screenshot-4.png` | one answer with its source links, same site (the question "Does it work with WordPress?") | 1280 x 800 |
| `screenshot-5.png` | the widget on a phone-sized screen (390 x 844 at 2x), same site | 780 x 1688 |

A screenshot's number matches its line under `== Screenshots ==` in
readme.txt. The logo files are Samomind's own artwork, taken from the Samomind logo pack, rasterised as they are and never redrawn; the wordmark is not retyped.
